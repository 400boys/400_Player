# Référence des raccourcis clavier, gestes souris et CLI (`SHORTCUTS.md`)

La table unique de vérité de toutes les commandes se trouve dans `crates/400_media_player/src/actions.rs` (58 actions). Appuyez sur **`F1`** (ou **`?`**) pour afficher l'aide des raccourcis, et sur **`Ctrl+K`** pour ouvrir la palette de commandes.

## Principaux raccourcis clavier
- `Espace` / `K` : Lecture / Pause
- `S` : Arrêter
- `F` / `F11` / `Alt+Entrée` : Plein écran
- `←` / `→` (`Maj+`, `Ctrl+`) : Reculer / Avancer (5 s, 10 s, 60 s)
- `.` / `,` : Image suivante / précédente en pause
- `[` / `]` / `Backspace` : Vitesse de lecture (0,25× à 4,0× avec maintien de la hauteur WSOLA)
- `↑` / `↓` / `M` : Volume / Muet
- `B` : Piste audio suivante
- `V` / `Ctrl+Maj+S` : Piste de sous-titres suivante / Charger un sous-titre externe
- `D` : Changer le mode de désentrelacement (`Auto` → `Désactivé` → `Toujours`)
- `A` / `Maj+A` : Ratio d'affichage / Mode d'ajustement
- `Maj+R` / `Maj+F` / `Ctrl+Maj+R` : Rotation 90° / Miroir horizontal / Réinitialiser l'image
- `Ctrl+E` / `Maj+N` : Égaliseur 10 bandes / Mode nuit
- `Maj+S` : Capture d'écran PNG
- `I` / `Ctrl+I` : Statistiques de lecture en direct / Informations média
- `Ctrl+L` / `Ctrl+P` / `Ctrl+K` : Liste de lecture / Réglages / Palette de commandes
